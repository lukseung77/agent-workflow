# Local Rules

This repository is a consumer of `agent-workflow-foundation/`. Its generic
startup and review behavior comes from that foundation and roles come from
`project-facts.md`.

## Product Target

Reviews and reusable rule additions, changes, or removals target foundation
product source by default. Local configuration and collaboration history are
this project's operational instance. Generalize a local improvement deliberately
before making it a product default.

## Maintainer Customization

- Overrides shared consultant reference-registry write exception: consultants in
  this repository write only their own collaboration file unless the human
  explicitly authorizes a specific additional action.
- Reason: protect the foundation product and the maintainer's local state while
  keeping independent review in separate files.
- Replacement: apply `agent-workflow-local/maintainer-governance.md` for product
  maintenance, consultant writes, human-approved changes, and source publication.

No missing-concurrence waiver or defined-term formatting change has been adopted.
Foundation and scaffold updates use the same lifecycle tool as other consumers,
with review and merges preserving this instance's local customizations.

## Grill Me

Grill Me and grilling are installed in this project's `.agents/skills/`.
Use the foundation's `workflow/grill-me.md` integration and question pacing;
this instance needs no additional interview override. Installed revision and
verification evidence remain in `agent-workflow-local/tooling.json`.
