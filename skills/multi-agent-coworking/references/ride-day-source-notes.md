# RideDay Source Notes

These notes are source material for improving the generic `multi-agent-coworking` skill.

Do not copy RideDay-specific product requirements into generic workflow files unless they represent a reusable collaboration pattern.

Reusable patterns observed:

- Codex acted as exploration lead.
- Gemini and Claude were treated as consultants.
- Consultant feedback was most helpful when it named contradictions, missed details, and file-boundary issues.
- Focused exploration files acted as source of truth.
- A short collaboration bootstrap acted as coordination and restart handoff file.
- The user preferred one-question-at-a-time exploration.
- Consultant suggestions became easier to manage once each had an explicit accept/reject reconciliation note.
