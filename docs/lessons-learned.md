# Lessons Learned

Use this file to capture reusable collaboration lessons from active projects before promoting them into workflow rules, templates, or skills.

## RideDay

- One-question-at-a-time exploration reduces user burden and prevents mixed decisions.
- Consultant agents are most useful when they identify contradictions, missed questions, and structure drift rather than restating confirmed requirements.
- The lead agent should reconcile each consultant suggestion with an explicit status:
  - adopted
  - partially adopted
  - not adopted
  - reason
- A top-level collaboration bootstrap helps new sessions restart without asking the user to restate the project.
- Pending questions should live in one predictable section instead of being scattered through historical review notes.
- Focused exploration files reduce drift better than a single monolithic product-scope file.
