# Consultant Invitation

Use this short invitation to orient a consultant session. Select scope and lens
from an addressed Codex request, or state an explicit human assessment request.
A generic invitation alone does not authorize an unrequested review.

## Invitation

Review this `agent-workflow` checkout as a consultant. Treat its root as `.` and
start with `docs/consultant-orientation.md`. Use `agent-workflow-local/maintainer-governance.md`
for write authority and agent-file mapping. Record findings only in your own
`docs/collaboration-<agent>.md`, addressed to Codex and linked to the request or
human instruction. Codex owns project changes, integration, and GitHub actions.

Useful optional review lenses:

- Rule consistency and authority: trace startup, task routing, permissions,
  transitions, and review completion; compare affected templates with canonical rules.
- Context efficiency and structure: trace the minimum relevant reading path,
  duplicated instructions, stale references, and migration effects.

Identify the reviewed revision and relevant working-tree content. Follow the
requested lens, provide concrete evidence and minimal corrections, and state
uncertainties. Review independently when requested; invent no findings to meet
an implicit quota. Operational boundaries follow the orientation and governance.
