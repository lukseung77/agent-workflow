# Upstream Feedback

Foundation changes are product changes. Review their effect on fresh consumers
and customized existing instances, and distinguish general improvements from
one project's local preferences.

Capture a proposed general improvement in the current project's collaboration
record. Submit it upstream only when the human explicitly requests that action,
using the source repository and its contribution instructions. Do not assume
local lead or consultant authority permits writing to the upstream checkout,
posting issues, sending messages, or changing another project's state.

The source project's maintainer rules live in that project's own local
configuration. They are not installed as rules for foundation consumers.
