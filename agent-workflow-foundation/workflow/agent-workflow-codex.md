## Host Guidance

- Keep `AGENTS.md`, hooks, and skills short; link focused rules and project files.
- Use available review tools and subagents only when useful for the task and permitted by the current assignment.
- Report sandbox, network, or approval constraints when they block work, affect the result, or require a user decision.
- Follow `workflow/agent-tooling.md` for configured Graphify, Ponytail, and RTK integrations; use `workflow/markitdown.md` for bulky references when relevant.
