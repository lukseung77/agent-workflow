# Existing Consumer Stage Compatibility

Only existing consumers without a selected project template use this fallback.
Preserve their local rules and former Exploration, Proposal, and Implementation
gates, now maintained in `templates/project-types/sw-development/stages.md`.
Reuse those stage definitions and transition protocol without adopting the
OpenSpec/GitHub template or requiring new integrations. Keep prior tooling-review
triggers until an explicit workflow change is agreed.

This compatibility path is not offered as a new-project template. Select a new
type/template for an existing consumer only through a separately reviewed local
workflow change, preserving accepted decisions, artifacts, and history.
